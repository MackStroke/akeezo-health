# Project instructions

Read [skill.md](skill.md) and [guide.md](guide.md) before implementation. This file applies to the proposed Akeezo MERN project when copied into its repository. It is not evidence of an existing codebase.

- Match the reference's audited page composition and route families.
- MongoDB, Express, React, Node.js and TypeScript are the implementation baseline.
- Use Akeezo's official assets and verified data. Fixtures must remain private.
- Keep public content, drafts, patient records and partner data in distinct access scopes.
- Complete admin → server → MongoDB → publish → public-render workflows.
- Preserve existing Akeezo URLs through explicit aliases and redirects.
- Use the acceptance criteria in testing.md. Record actual commands/results in the implementation completion report.
- Do not deploy publicly or replace akeezo.com without owner approval.
